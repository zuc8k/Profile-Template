🇬🇧 English Documentation

01. Project Overview

Zucks is a creative, single-page interactive portfolio template designed to redefine how personal identities are presented on the web.

Built around a unique particle-based visual system, the experience uses a single unified collection of animated points that dynamically rearranges itself into different scenes.

Instead of conventional scrolling and static sections, Zucks introduces a state-driven navigation experience where every scene becomes an interactive part of the portfolio.

One visual system. Multiple scenes. One seamless experience.

02. Core Features

* Dynamic Particle System — Animated points continuously transform into different visual compositions.
* Scene-Based Navigation — Explore the portfolio through interactive visual states.
* Zero-Scroll Experience — No traditional page scrolling between sections.
* Multiple Interaction Methods — Navigate using mouse clicks, keyboard controls, and touch gestures.
* Fluid Scene Transitions — Smooth transformations between different states.
* Responsive Interaction — Designed to support desktop and mobile devices.
* Bilingual Experience — Dedicated Arabic and English portfolio templates.
* Production Build Pipeline — Bundled and obfuscated JavaScript with optimized CSS.
* Static Hosting Compatibility — Deployable through standard static web servers.

03. Interaction System

Zucks replaces traditional website navigation with a dynamic scene-management system.

Each scene represents a different visual state. When navigation occurs, the particle system rearranges its composition to create a seamless transition into the next scene.

Input	Action
Mouse Click	Navigate between scenes
Keyboard	Switch between visual states
Touch Swipe	Navigate on mobile devices

04. Installation & Setup

Requirements

* Node.js
* npm
* Python 3.x

Clone the Repository

git clone <repository-url>
cd Zucks

Install Dependencies

npm install

Build for Production

npm run build

The production build generates an optimized dist/ directory containing bundled and minified assets.

Start the Local Server

python serve.py

Local Address:

http://127.0.0.1:8765

05. Production & Optimization

The production build performs:

* JavaScript bundling.
* JavaScript obfuscation.
* CSS minification.
* Exclusion of original js/ modules.
* Removal of source maps from the served production directory.

Source Code Notice: Obfuscation makes browser-side code harder to read, but it does not prevent users from downloading or inspecting client-side assets.

06. Deployment

Zucks supports standard static hosting environments, including:

* Nginx
* Node.js static servers
* Python HTTP servers
* Static hosting platforms supporting SPA rewrites

Important: ES modules require HTTP serving. Directly opening index.html using file:// is not supported.

The included local server listens exclusively on 127.0.0.1:8765. Public traffic is handled through a dedicated Nginx virtual host for zucks.ddns.net.

🇪🇬 التوثيق العربي

01. نبذة عن المشروع

Zucks هو قالب بورتفوليو شخصي تفاعلي من صفحة واحدة، صُمم لتقديم تجربة مختلفة في عرض الهوية الشخصية على الإنترنت.

يعتمد المشروع على نظام بصري مبتكر يتكون من مجموعة موحدة من النقاط المتحركة، والتي يعاد ترتيبها ديناميكيًا لتكوين مشاهد وأشكال بصرية مختلفة.

بدلًا من التنقل التقليدي والتمرير بين الأقسام، يقدم Zucks نظامًا تفاعليًا يعتمد على المشاهد والحالات المتغيرة.

نظام بصري واحد. مشاهد متعددة. تجربة متكاملة.

02. المميزات الأساسية

* نظام نقاط متحركة يعيد تشكيل نفسه باستمرار.
* التنقل بين المشاهد دون الحاجة إلى تمرير الصفحة.
* انتقالات بصرية سلسة بين الحالات المختلفة.
* دعم النقر باستخدام الماوس.
* دعم التنقل باستخدام لوحة المفاتيح.
* دعم السحب باللمس على الهواتف.
* تصميم يدعم العربية والإنجليزية.
* نظام بناء للإنتاج يتضمن تجميع وضغط ملفات JavaScript وCSS.
* إمكانية النشر على خوادم الاستضافة الثابتة.

03. طريقة التفاعل

يعتمد Zucks على نظام تنقل مختلف عن المواقع التقليدية.

كل مشهد يمثل حالة بصرية مستقلة، وعند الانتقال إلى مشهد آخر يعيد النظام ترتيب النقاط المتحركة لتكوين المشهد الجديد بسلاسة.

04. التثبيت والتشغيل

المتطلبات:

* Node.js
* npm
* Python 3.x

تثبيت المكتبات:

npm install

بناء نسخة الإنتاج:

npm run build

تشغيل السيرفر المحلي:

python serve.py

رابط التشغيل المحلي:

http://127.0.0.1:8765

05. تحسينات الإنتاج

يقوم نظام البناء بتنفيذ:

* تجميع ملفات JavaScript.
* تشويش الكود البرمجي.
* ضغط ملفات CSS.
* استبعاد ملفات JavaScript الأصلية من نسخة الإنتاج.
* إزالة Source Maps من مجلد الإنتاج.

ملاحظة: تشويش الكود يزيد صعوبة قراءته، لكنه لا يمنع تحميل ملفات المتصفح أو تحليلها.

06. النشر والاستضافة

يدعم المشروع خوادم الاستضافة الثابتة مثل:

* Nginx
* Node.js Static Servers
* Python HTTP Servers
* منصات الاستضافة التي تدعم SPA Rewrites

يجب تشغيل المشروع عبر HTTP، حيث إن فتح index.html مباشرة باستخدام file:// غير مدعوم.

السيرفر المحلي يستمع على 127.0.0.1:8765 فقط، ويتم استقبال الاتصالات العامة من خلال Nginx Virtual Host مخصص للنطاق zucks.ddns.net.
